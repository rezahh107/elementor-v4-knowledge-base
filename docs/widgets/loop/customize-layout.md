# جزوه جامع Customize the layout of a Loop Grid در Elementor

## مشخصات منبع

- مقاله رسمی: `Customize the layout of a Loop Grid`
- URL رسمی: `https://elementor.com/help/customize-layout-loop/`
- آخرین به‌روزرسانی ثبت‌شده در صفحه: `September 2, 2025`
- دامنه بررسی: فقط متن و تصاویر رسمی همین صفحه.
- وضعیت شواهد: `completed_with_gaps`

این سند درباره صفحه‌ای است که پس از ساخت یک `Loop Grid`، نحوه کنترل ظاهر و چیدمان آیتم‌های آن را توضیح می‌دهد. مقاله کوتاه است و فقط بخش `Layout` از تب `Content` را برای Loop Grid توضیح می‌دهد.

## documented — موارد صریح متن مقاله

### هدف صفحه

مقاله می‌گوید `Loop Grid` برای ساخت فهرست‌های بسیار سفارشی‌شده از نوشته‌ها استفاده می‌شود تا ظاهر سایت یکتا شود. پس از ساخت Loop Grid، می‌توان نحوه نمایش ورودی‌ها یا آیتم‌ها را سفارشی کرد.

### مسیر دسترسی به تنظیمات Layout

برای تعیین چیدمان Loop Grid، مراحل رسمی صفحه این‌ها هستند:

1. `Loop Grid` را انتخاب کنید.
2. مقاله می‌گوید احتمالاً ساده‌ترین راه برای دسترسی به Loop Grid استفاده از `Structure window` است.
3. به `Content tab` بروید.
4. بخش `Layout` را باز کنید.

ترجمه اصطلاحات:

- `Loop Grid` — گرید حلقه / شبکه تکرارشونده
- `Structure window` — پنجره ساختار
- `Content tab` — تب محتوا
- `Layout section` — بخش چیدمان

### کارهای قابل انجام در Layout

متن رسمی فقط این کارها را زیر `Layout` ثبت می‌کند:

#### Switch to an existing different loop template — تغییر به یک Loop Template موجود دیگر

کاربر می‌تواند به یک `loop template` موجود دیگر تغییر دهد. روش رسمی صفحه:

- در `Choose a template textbox` نام Loop موردنظر را تایپ کنید.
- سپس آن را از `dropdown menu` انتخاب کنید.

نکته شواهد: مقاله فقط انتخاب یک Template موجود را توضیح می‌دهد. ساخت Template جدید، ویرایش جزئیات Template یا Theme Builder را در همین صفحه توضیح نمی‌دهد.

#### Change the number of columns on the page — تغییر تعداد ستون‌های صفحه

مقاله می‌گوید می‌توانید تعداد ستون‌ها را در صفحه تغییر دهید. اثر این گزینه این است که تعداد نوشته‌ها/لیستینگ‌هایی که کاربران در هر ردیف می‌بینند تغییر می‌کند.

مقاله همچنین می‌گوید می‌توان این گزینه را همراه با محدودکردن تعداد آیتم‌ها در هر صفحه استفاده کرد تا طراحی تنظیم شود. توصیه رسمی صفحه این است که چند ترکیب مختلف امتحان شود تا بهترین حالت پیدا شود.

#### Set how many items will appear on a page — تعیین تعداد آیتم‌های قابل نمایش در هر صفحه

مقاله می‌گوید این Field تعداد نوشته‌هایی را که در صفحه نمایش داده می‌شوند کنترل می‌کند. ترکیب این گزینه با تعداد ستون‌ها تعیین می‌کند چند ردیف دیده شود.

مثال رسمی صفحه:

- اگر در مجموع `six posts` نمایش داده شود؛
- و Layout دارای `three column` باشد؛
- هر صفحه شامل `two rows of three items` خواهد بود.

ترجمه اصطلاحات:

- `items per page` — تعداد آیتم‌ها در هر صفحه
- `columns` — ستون‌ها
- `rows` — ردیف‌ها
- `posts/listings` — نوشته‌ها/لیستینگ‌ها

#### Turn Masonry on and off — روشن/خاموش کردن Masonry

مقاله می‌گوید `Masonry setting` آیتم‌ها را به‌صورت خودکار مرتب می‌کند تا بهترین استفاده از فضای موجود صفحه انجام شود.

در متن کنار تصاویر، مقاله این مقایسه را می‌آورد:

- یک Loop با `Masonry turned off` نمایش داده شده است.
- در تصویر دیگر، با روشن‌شدن Masonry فاصله بین ردیف‌ها به‌صورت خودکار کمتر شده تا از فضای موجود استفاده شود.

## derived — برداشت‌های محدود و برچسب‌خورده

- چون صفحه می‌گوید تعداد ستون‌ها و تعداد آیتم‌ها را با هم می‌توان برای تنظیم Design ترکیب کرد، می‌توان نتیجه گرفت کنترل ردیف‌های قابل مشاهده از رابطه بین `Items per page` و `Columns` به‌دست می‌آید. این برداشت فقط در سطح طراحی است و رفتار Query، Pagination یا Runtime را اثبات نمی‌کند.
- چون صفحه فقط انتخاب Template موجود را توضیح می‌دهد، این مقاله برای آموزش ساخت Loop Template کافی نیست.
- چون Masonry در متن رسمی برای استفاده بهتر از فضای موجود معرفی شده، می‌توان آن را یک کنترل چیدمان بصری دانست؛ اما نحوه محاسبه دقیق Masonry، ترتیب DOM یا رفتار در Breakpointها از این صفحه قابل اثبات نیست.
- اشاره به `Prev: Build a loop grid` و `Up Next: Paginate your loop` فقط رابطه ناوبری مقاله‌ها را نشان می‌دهد. محتوای آن صفحات بدون بررسی مستقل به این سند نسبت داده نمی‌شود.

## ارتباط با موضوع‌های درخواستی

### پیش‌نیازها

صفحه فقط می‌گوید `After building a Loop Grid` می‌توان نحوه نمایش Entryها را سفارشی کرد. بنابراین پیش‌نیاز صریح همین است: Loop Grid باید ساخته شده باشد. جزئیات نصب، طرح Pro، ساخت Loop Item یا تنظیمات Theme Builder در این صفحه توضیح داده نشده است.

### ساخت یا انتخاب Loop Template

صفحه فقط انتخاب یک Template موجود دیگر را توضیح می‌دهد: در `Choose a template textbox` نام Loop تایپ و سپس از Dropdown انتخاب می‌شود. ساخت Template جدید در صفحه توضیح داده نشده است.

### Layout، Columns و Items Per Page

صفحه این سه مفهوم را مستقیم توضیح می‌دهد:

- `Layout` محل کنترل چیدمان آیتم‌ها است.
- `Columns` تعداد آیتم‌های قابل مشاهده در هر Row را تحت‌تأثیر قرار می‌دهد.
- `Items per page` تعداد کل پست‌های نمایش‌داده‌شده در صفحه را کنترل می‌کند.

مثال رسمی صفحه برای ترکیب این دو کنترل: ۶ پست در ۳ ستون برابر با ۲ ردیف سه‌تایی است.

### Masonry

صفحه می‌گوید Masonry را می‌توان روشن و خاموش کرد. Masonry آیتم‌ها را خودکار مرتب می‌کند تا از فضای موجود صفحه بهترین استفاده شود. در نمونه رسمی، روشن‌شدن Masonry فاصله بین Rowها را کاهش داده است.

### Equal Height

در متن این صفحه گزینه‌ای با نام `Equal Height` ثبت نشده است. بنابراین درباره وجود، نبود، مقدار یا رفتار آن در این سند ادعایی نمی‌شود.

### اندازه و فاصله ردیف‌ها و ستون‌ها

صفحه کنترل مستقیمی برای اندازه ستون‌ها، Gap ستون‌ها یا Row Gap را توضیح نمی‌دهد. فقط اثر Masonry بر کاهش فاصله بین ردیف‌ها در مثال تصویری ذکر شده است.

### ترتیب و جهت چیدمان

صفحه درباره Direction، Ordering، RTL، ترتیب DOM یا ترتیب Query توضیحی نمی‌دهد. فقط می‌گوید Masonry آیتم‌ها را خودکار برای استفاده بهتر از فضای موجود مرتب می‌کند.

### Responsive controls

صفحه کنترل Responsive، Breakpoint یا تنظیم جداگانه موبایل/تبلت را توضیح نمی‌دهد.

### Interaction با Loop Template، Query و Pagination

- Loop Template: فقط تغییر به Template موجود توضیح داده شده است.
- Query: صفحه درباره Query، Source، Include/Exclude یا Sort چیزی توضیح نمی‌دهد.
- Pagination: صفحه فقط در مثال طراحی به تعداد آیتم‌ها در صفحه اشاره دارد و لینک ناوبری `Up Next: Paginate your loop` دارد؛ رفتار Pagination در همین صفحه توضیح داده نشده است.

### Style controls

صفحه Style tab، رنگ، Typography، Border، Spacing یا Background را توضیح نمی‌دهد. فقط Layout در Content tab بررسی می‌شود.

### Display conditions

صفحه هیچ توضیحی درباره Display Conditions ارائه نمی‌کند.

### مثال‌ها

مثال عددی رسمی:

- مجموع ۶ پست؛
- چیدمان ۳ ستونه؛
- نتیجه: ۲ Row با ۳ Item در هر Row.

مثال تصویری رسمی:

- مقایسه Masonry خاموش و روشن؛
- در حالت روشن، فاصله بین ردیف‌ها کاهش یافته و فضای صفحه بهتر استفاده شده است.
