# Image element — جزوه جامع فارسی Elementor Editor V4

> **دامنه این جزوه:** فقط متن و تصاویر تعبیه‌شده در صفحه رسمی Elementor با عنوان `Image element` بررسی شده‌اند. صفحات فرعی مانند `Layout`، `Spacing`، `Size`، `Position`، `Typography`، `Background`، `Border`، `Effects`، `Dynamic tags`، `Responsive editing` و مقاله V3 با عنوان `Image widget` بدون بررسی مستقل، منبع factual این سند محسوب نمی‌شوند.

## 1. مشخصات منبع

| فیلد | مقدار |
|---|---|
| عنوان مقاله | `Image element` |
| URL رسمی | <https://elementor.com/help/image-element/> |
| ناشر | Elementor Knowledge Hub |
| آخرین به‌روزرسانی اعلام‌شده | `May 26, 2026` |
| دامنه صریح | کاربران `Editor v4` |
| ارجاع V3 | مقاله جداگانه `Image widget` |

| نسخه دقیق Elementor | در صفحه اعلام نشده |
| نوع Plan یا پیش‌نیاز Pro | در صفحه اعلام نشده |
| وضعیت پوشش | `completed_with_gaps` |

**[documented]** صفحه صریحاً می‌گوید این مقاله برای کاربران `Editor v4` است و کاربران Editor v3 را به مقاله جداگانه `Image widget` ارجاع می‌دهد.

**[insufficient_evidence]** عبارت `Editor v4` نسخه دقیق افزونه، شماره Build، حداقل نسخه WordPress، وضعیت Beta/Stable یا نوع اشتراک لازم را تعیین نمی‌کند.

## 2. قرارداد وضعیت شواهد

- **documented:** مطلب به‌طور صریح در متن رسمی همین صفحه آمده است.
- **observed:** مطلب مستقیماً در تصویر رسمی همین صفحه دیده شده است، اما متن رفتار آن را تعریف نکرده است.
- **derived:** نتیجه‌ای محدود و قابل ردیابی از شواهد همین صفحه است؛ حقیقت مستقل محصول یا قرارداد Runtime نیست.
- **insufficient_evidence:** صفحه برای نتیجه‌گیری دقیق یا کامل شواهد کافی ندارد.

نبود یک کنترل در این مقاله، اثبات نبود آن در محصول نیست.

## 3. خلاصه اجرایی

**[documented]** `Image element` برای افزودن و سفارشی‌سازی تصویر در وب‌سایت معرفی شده است. مقاله قابلیت‌های سطح‌بالای زیر را نام می‌برد:

1. Upload یا Select کردن تصویر؛
2. تنظیم Size و Alignment؛
3. اعمال Hover effects و Filters؛
4. لینک‌کردن تصویر به URL مشخص؛
5. انتخاب Resolution؛
6. بازکردن لینک در تب جدید.

**[documented]** دو مسیر منبع تصویر در راهنمای مرحله‌ای وجود دارد:

- انتخاب تصویر از `Media Library`؛
- استفاده از تصویر آنلاین با واردکردن URL.

**[documented]** مقاله فقط کنترل‌های اختصاصی `Image`، `Resolution`، `Link`، `Open in a new tab` و عنوان بدون توضیح `ID` را در متن تنظیمات نام می‌برد.

**[documented]** صفحه دسته‌های Style مشترک `Layout`، `Spacing`، `Size`، `Position`، `Typography`، `Background`، `Border` و `Effects` را لینک می‌کند، اما کنترل‌های داخل این دسته‌ها را در خود مقاله توضیح نمی‌دهد.

**[insufficient_evidence]** این مقاله برای Aspect Ratio، Object Fit، Object Position، Width/Height دقیق، Lazy Loading، Responsive values، Dynamic Data، Classes، Variables، Front-end accessibility، SEO و رفتار Runtime جزئیات صریح کافی ارائه نمی‌کند.

## 4. اصطلاحات و ناهماهنگی‌های خود منبع

### 4.1. Element و Widget

**[documented]** عنوان مقاله و بخش‌های اصلی از اصطلاح `Image element` استفاده می‌کنند، اما دستورهای افزودن و حذف چند بار از واژه `widget` بهره می‌برند.

**[derived]** این ناهماهنگی واژگانی برای استنتاج معماری داخلی، سازگاری V3/V4 یا یکسان‌بودن کامل Widget و Element کافی نیست.

### 4.2. ارجاع اشتباه به Paragraph widget

**[documented]** پس از معرفی Image element، صفحه جمله‌ای با مضمون دیدن گزینه‌های `Paragraph widget` دارد.

**[derived]** با توجه به موضوع صفحه، این جمله احتمالاً ناهماهنگی ویرایشی است؛ با این حال این سند آن را اصلاح رسمی یا شاهد انتقال تنظیمات Paragraph به Image تلقی نمی‌کند.

### 4.3. تکرار Resolution و Link

**[documented]** متن استخراج‌شده صفحه، توضیح `Resolution`، `Link` و `Open in a new tab` را دو بار در بخش General نمایش می‌دهد.

**[insufficient_evidence]** صفحه روشن نمی‌کند این تکرار ناشی از ساختار Tab، خطای انتشار، نسخه‌های هم‌زمان رابط یا صرفاً نحوه Render محتوای Help Center است.

## 5. افزودن و حذف Image element

### 5.1. افزودن به Canvas

**[documented]** روند عمومی افزودن:

1. در Elementor Editor روی علامت `+` کلیک کنید؛
2. فهرست Elementها/Widgetهای موجود نمایش داده می‌شود؛
3. Image را کلیک کنید یا آن را به Canvas بکشید.

**[observed]** تصویر رسمی `Add-the-element-to-the-canvas-scaled.png` پنل `Edit Image` را کنار Canvas نشان می‌دهد. در این تصویر Tabهای `General` و `Style` و بخش `Content` قابل مشاهده‌اند.

### 5.2. حذف از Canvas

**[documented]** روند حذف:

1. Image element را با کلیک روی آن در Canvas انتخاب کنید؛
2. کلید `Delete` صفحه‌کلید را فشار دهید.

**[derived]** این دستور یک تعامل ویرایشی با صفحه‌کلید است؛ به‌تنهایی شاهد Accessibility خروجی Front-end یا پشتیبانی از کلیدهای دیگر نیست.

## 6. هدف و موارد استفاده

### 6.1. مورد استفاده اصلی مقاله

**[documented]** مثال اصلی درباره وب‌سایت یک کافه است که در بالای Homepage به تصویر شاخصی برای جلب توجه مشتریان بالقوه نیاز دارد.

### 6.2. موارد استفاده تکمیلی

**[documented]** مقاله سه نمونه دیگر ارائه می‌کند:

- ساخت Portfolio gallery و لینک‌کردن هر تصویر به صفحه پروژه یا نمای جزئیات؛
- ساخت Banner یا Poster برای رویداد و Webinar؛
- نمایش Before/After برای بازسازی خانه، پیشرفت تناسب اندام یا فرایندهای تحول مشابه.

**[insufficient_evidence]** مقاله برای Gallery behavior، Lightbox، تعداد تصاویر، ترتیب Grid، Modal، Carousel یا مقایسه تعاملی Before/After تنظیمی ارائه نمی‌کند؛ مثال‌ها فقط سناریوی استفاده‌اند.

## 7. راهنمای رسمی مرحله‌به‌مرحله

### مرحله 1 — افزودن Image

**[documented]** Image را به Canvas اضافه کنید. گزینه‌های Image element در پنل سمت چپ ظاهر می‌شوند.

### مرحله 2 — انتخاب منبع تصویر

**[documented]** در `General tab` روی فیلد `Image` بروید و `Select Image` را انتخاب کنید.

**[documented]** به‌عنوان مسیر جایگزین، می‌توان URL یک تصویر آنلاین را وارد کرد.

**[observed]** تصویر رسمی `Choose-select-image.png` موارد زیر را نشان می‌دهد:

- عنوان پنل `Edit Image`؛
- Tabهای `General`، `Style` و `Interactions`؛
- بخش `Content`؛
- Card مربوط به Image؛
- دکمه `Select image`؛
- گزینه `Insert from URL`؛
- `Resolution` با مقدار نمونه `Full`؛
- بخش `Settings`؛
- `Link`، `ID`، `Attributes` و `Display Conditions`.

**[insufficient_evidence]** تصویر رفتار، اعتبارسنجی URL، فرمت‌های مجاز، CORS، Hotlinking، Cache، Proxy، Download، امنیت یا نحوه ذخیره URL را توضیح نمی‌دهد.

### مرحله 3 — Media Library

**[documented]** از Media Library یک تصویر انتخاب کنید و روی `Select` کلیک کنید.

**[observed]** تصویر رسمی `Choose-a-file-and-click-select-1.png` رابط WordPress Media را نشان می‌دهد و شامل این موارد قابل مشاهده است:

- `Upload files`؛
- `Media Library`؛
- `Filter media` و مقدار نمونه `All`؛
- `Search media`؛
- `Attachment Details`؛
- فیلدهای `Alt Text`، `Title`، `Caption` و `Description`؛
- دکمه `Select`.

**[observed]** همان تصویر یک فایل نمونه با نام `34-BarCafe-hero.jpg`، تاریخ `April 14, 2025`، حجم `1 MB` و ابعاد `1840 by 1066 pixels` نشان می‌دهد. این‌ها اطلاعات نمونه همان Asset هستند، نه محدودیت یا مقدار پیش‌فرض Image element.

### مرحله 4 — Resolution

**[documented]** مثال مقاله `Image Resolution` را روی `Full` نگه می‌دارد و می‌گوید کاربر می‌تواند بسته به نیاز از Dropdown، Resolution دیگری انتخاب کند.

**[derived]** `Full` در این جمله یک انتخاب آموزشی برای مثال کافه است و از متن نمی‌توان آن را Default رسمی همه Image elementها دانست.

### مرحله 5 — Link

**[documented]** برای افزودن لینک:

1. علامت `+` کنار `Link` را انتخاب کنید؛
2. URL صفحه مقصد را در Text box مربوط به Link وارد کنید؛
3. کلیک بازدیدکننده روی تصویر، URL ثبت‌شده را باز می‌کند.

**[observed]** تصویر `enter-the-URL-3-154x300.png` یک URL نمونه و Toggle با عنوان `Open in a new tab` را نشان می‌دهد.

## 8. فهرست کنترل‌های General

| کنترل انگلیسی | ترجمه فارسی | وضعیت شواهد | آنچه صفحه اثبات می‌کند |
|---|---|---|---|
| `Image` | تصویر | documented | برای افزودن تصویر به Element کلیک می‌شود. |
| `Select Image` | انتخاب تصویر | documented + observed | انتخاب از جریان Media Library را آغاز می‌کند. |
| `Insert from URL` | درج از URL | documented + observed | امکان استفاده از تصویر آنلاین با URL وجود دارد. |
| `Resolution` / `Image Resolution` | وضوح/رزولوشن تصویر | documented | کیفیت تصویر با Dropdown انتخاب می‌شود. |
| `Full` | کامل | documented as example + observed | در مثال رسمی انتخاب شده؛ Default عمومی اثبات نشده است. |
| `Link` | پیوند | documented | با علامت Plus باز می‌شود و URL مقصد می‌پذیرد. |
| `Open in a new tab` | بازکردن در تب جدید | documented + observed | در صورت وجود Link می‌توان آن را فعال کرد. |
| `ID` | شناسه | documented label only + observed | عنوان کنترل وجود دارد؛ معنا و رفتار آن توضیح داده نشده است. |
| `Attributes` | ویژگی‌ها | observed | در تصویر رسمی به‌صورت بخش قابل گسترش دیده می‌شود؛ متن جزئیات ندارد. |
| `Display Conditions` | شرایط نمایش | observed | در تصویر رسمی دیده می‌شود؛ متن مقاله رفتار یا قواعد آن را شرح نمی‌دهد. |
| `Interactions` | تعامل‌ها | observed | در تصویر 2026 به‌صورت Tab دیده می‌شود؛ متن مقاله تنظیمات آن را شرح نمی‌دهد. |

### 8.1. Image

**[documented]** با کلیک روی Image می‌توان یک تصویر به Element افزود.

**[insufficient_evidence]** صفحه روند صریح Replace، Remove، Clear، Reset، Re-select، حفظ Link هنگام جایگزینی، History/Undo و رفتار حذف فایل از Media Library را توضیح نمی‌دهد.

### 8.2. Resolution

**[documented]** Resolution کیفیت تصویر را تعیین می‌کند؛ Resolution بالاتر با کیفیت بالاتر و فایل بزرگ‌تر همراه است و ممکن است زمان بارگذاری صفحه را تحت تأثیر قرار دهد.

**[insufficient_evidence]** صفحه موارد زیر را اعلام نمی‌کند:

- فهرست کامل گزینه‌های Dropdown؛
- ارتباط گزینه‌ها با WordPress image sizes؛
- Width/Height خروجی؛
- `srcset` و `sizes`؛
- Cropping؛
- Upscaling؛
- فرمت یا Compression؛
- رفتار Retina/HiDPI؛
- مقادیر پیش‌فرض؛
- تفاوت منبع Media Library و URL آنلاین در Resolution.

### 8.3. Link

**[documented]** Image می‌تواند به URL مشخص لینک شود و کلیک روی آن لینک را باز کند.

**[documented]** `Open in a new tab` فقط در زمینه Image دارای Link توضیح داده شده است.

**[insufficient_evidence]** صفحه درباره این موارد توضیح نمی‌دهد:

- Target دقیق HTML؛
- `rel`، `nofollow`، `noopener` یا `noreferrer`؛
- Custom Attributes مربوط به Link؛
- پروتکل‌های مجاز؛
- Dynamic URL؛
- Lightbox یا Media File link؛
- Nested links؛
- رفتار لینک در Editor؛
- Analytics یا event tracking؛
- حالت‌های Disabled/Error.

### 8.4. ID، Attributes و Display Conditions

**[documented]** `ID` در متن بخش General نام برده شده، اما هیچ تعریف یا مثال همراه آن نیست.

**[observed]** `Attributes` و `Display Conditions` در تصویر رسمی رابط دیده می‌شوند.

**[insufficient_evidence]** این مقاله Syntax، Validation، Scope، HTML output، precedence، شرط‌ها، inheritance یا Runtime behavior این سه مورد را مشخص نمی‌کند.

## 9. Media Library، Alt Text و Caption

### 9.1. رفتار مستند Media Library

**[documented]** کاربر می‌تواند یک تصویر را از Media Library انتخاب کند و با `Select` آن را به Image element اختصاص دهد.

### 9.2. فیلدهای مشاهده‌شده

**[observed]** در تصویر رسمی Media Library فیلدهای زیر دیده می‌شوند:

- `Alt Text` — متن جایگزین؛
- `Title` — عنوان؛
- `Caption` — زیرنویس؛
- `Description` — توضیحات.

**[insufficient_evidence]** مقاله مشخص نمی‌کند:

- Image element کدام‌یک از این فیلدها را در Front-end Render می‌کند؛
- Alt از Media Library به‌صورت خودکار خوانده، کپی یا Override می‌شود؛
- Caption در خروجی نمایش داده می‌شود یا نه؛
- تغییر Metadata پس از انتخاب، خروجی Element را به‌روزرسانی می‌کند یا نه؛
- Image URL آنلاین راهی برای تعریف Alt Text دارد یا نه؛
- Decorative image یا Alt خالی چگونه مدیریت می‌شود.

**[derived]** حضور Alt Text در Screenshot فقط وجود این فیلد در پنجره Media انتخاب‌شده را اثبات می‌کند؛ از آن نمی‌توان Accessibility نهایی Image element را نتیجه گرفت.

## 10. Size، Dimensions، Alignment و نسبت تصویر

### 10.1. آنچه صریحاً گفته شده

**[documented]** معرفی مقاله می‌گوید Image element امکان تنظیم `size` و `alignment` را دارد.

**[documented]** صفحه `Size` و `Layout` را در فهرست Style options قرار می‌دهد.

### 10.2. آنچه توضیح داده نشده

**[insufficient_evidence]** مقاله کنترل، واحد، مقدار یا رفتار دقیق موارد زیر را ارائه نمی‌کند:

- Width و Height؛
- Min/Max size؛
- Inline size و Block size؛
- Alignment options و ارتباط آن‌ها با Writing mode؛
- Aspect Ratio؛
- Object Fit؛
- Object Position؛
- Intrinsic dimensions؛
- Overflow؛
- Stretching؛
- Cropping؛
- Container alignment؛
- Breakpoint-specific dimensions.

**[derived]** نام‌بردن `Size` و `Alignment` یک قابلیت سطح‌بالا را اثبات می‌کند، نه Inventory کامل کنترل‌ها یا رفتار CSS آن‌ها را.

## 11. Style tab و دسته‌های مشترک

**[documented]** مقاله این دسته‌ها را به‌عنوان Style options لینک می‌کند:

| عنوان انگلیسی | ترجمه فارسی | دامنه اثبات‌شده در این مقاله |
|---|---|---|
| `Layout` | چیدمان | فقط وجود لینک/دسته |
| `Spacing` | فاصله‌گذاری | فقط وجود لینک/دسته |
| `Size` | اندازه | فقط وجود لینک/دسته |
| `Position` | موقعیت | فقط وجود لینک/دسته |
| `Typography` | تایپوگرافی | فقط وجود لینک/دسته؛ کاربرد آن برای Image توضیح داده نشده |
| `Background` | پس‌زمینه | فقط وجود لینک/دسته |
| `Border` | حاشیه | فقط وجود لینک/دسته |
| `Effects` | افکت‌ها | فقط وجود لینک/دسته |

**[documented]** معرفی مقاله صریحاً به Hover effects و Filters اشاره می‌کند.

**[insufficient_evidence]** بدون بررسی مستقل صفحات لینک‌شده، این سند نمی‌تواند برای دسته‌های بالا موارد زیر را ثبت کند:

- نام کنترل‌های فرعی؛
- Default values؛
- Units؛
- Responsive inheritance؛
- Normal/Hover/Focus states؛
- CSS output؛
- Transition timing؛

## 21. Workflow عملی فقط بر اساس شواهد صفحه

1. در Editor روی `+` کلیک کنید.
2. Image element را کلیک کنید یا به Canvas بکشید.
3. در `General > Image`، `Select Image` را انتخاب کنید.
4. تصویر را از Media Library انتخاب و `Select` کنید؛ یا از `Insert from URL` برای تصویر آنلاین استفاده کنید.
5. از `Resolution` کیفیت مناسب نیاز خود را انتخاب کنید؛ مقاله هشدار می‌دهد کیفیت بالاتر می‌تواند فایل بزرگ‌تر و Loading کندتر ایجاد کند.
6. برای لینک‌کردن تصویر، Plus کنار `Link` را باز کنید و URL مقصد را وارد کنید.
7. در صورت نیاز `Open in a new tab` را فعال کنید.
8. Style را فقط در حد دسته‌های فهرست‌شده بررسی کنید؛ جزئیات آن‌ها در این مقاله مستند نشده است.
9. برای حذف، Element را انتخاب و کلید `Delete` را فشار دهید.

**[insufficient_evidence]** این Workflow نباید با Defaults، کنترل‌های Style، Accessibility یا Runtime behavior حدس‌زده‌شده تکمیل شود.

## 23. جمع‌بندی

**[documented]** Image element در Editor V4 مسیر ساده‌ای برای افزودن تصویر از Media Library یا URL، انتخاب Resolution، لینک‌کردن تصویر و بازکردن لینک در تب جدید ارائه می‌کند. مقاله همچنین قابلیت‌های کلی Size، Alignment، Hover effects و Filters را نام می‌برد و دسته‌های Style مشترک را لینک می‌کند.

**[observed]** تصاویر رسمی جزئیات بیشتری از رابط، از جمله Media metadata، Attributes، Display Conditions و Interactions را نشان می‌دهند، اما ظاهر رابط به‌تنهایی رفتار پنهان یا Default را اثبات نمی‌کند.

**[derived]** این صفحه برای Onboarding و شناخت کنترل‌های اصلی مناسب است، ولی مرجع کامل Schema یا Runtime contract عنصر Image نیست.

**[insufficient_evidence]** برای پاسخ قطعی درباره Aspect Ratio، Object Fit، Responsive، Dynamic Data، Classes/Variables، Lazy Loading، Accessibility، SEO و جزئیات Style باید منابع رسمی مربوطه به‌طور مستقل بررسی یا Fixture کنترل‌شده اجرا شود.
