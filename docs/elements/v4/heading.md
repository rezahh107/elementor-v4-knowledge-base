## روایت آموزشی بر پایه Claimها

### هدف و دامنه

Heading element برای ساخت عنوان‌ها و تیترهای صفحه در Editor V4 استفاده می‌شود. منبع رسمی آن را برای کاربران Editor V4 معرفی می‌کند و برای کاربران Editor V3 به مقاله جداگانه Heading widget ارجاع می‌دهد. بنابراین این سند نباید تنظیمات یا رفتارهای V3 را به Heading element در V4 منتقل کند. این بخش بر پایه `CLM-KB-005-001` و `CLM-KB-005-004` است.

### افزودن و حذف Heading

برای افزودن Heading، ابتدا در Elementor Editor روی `+` کلیک می‌شود؛ سپس Heading با کلیک یا Drag روی Canvas قرار می‌گیرد. برای حذف، Heading روی Canvas انتخاب می‌شود و کلید `Delete` صفحه‌کلید فشار داده می‌شود. این مراحل از `CLM-KB-005-002` و `CLM-KB-005-003` می‌آیند.

### سناریوهای کاربرد

منبع رسمی چند سناریو را مستند می‌کند: عنوان صفحه یا بخش مهم، عنوان و زیرعنوان Blog post، Heading برای Testimonial، و عنوان تعاملی Call-to-Action. مثال رسمی یک سایت نانوایی را نشان می‌دهد که از متن `Baking With Love` و Tag نمونه `<h1>` برای مزیت SEO استفاده می‌کند. این مثال مقدار پیش‌فرض محصول نیست و فقط سناریوی آموزشی است. این بخش بر پایه `CLM-KB-005-005` و `CLM-KB-005-006` است.

### General tab — تب General

در `General tab` کنترل‌های اصلی مستند عبارت‌اند از:

- `Title` — عنوان: متنی که در Heading نمایش داده می‌شود.
- `Tag` / `HTML Tag` — تگ HTML: تگ HTML Heading را انتخاب می‌کند و به فهم ساختار سایت توسط موتورهای جستجو کمک می‌کند.
- `Link` — پیوند: با کلیک روی plus sign می‌توان URL مقصد را وارد کرد.
- `Open in a new tab` — بازکردن در تب جدید: پس از افزودن Link ظاهر می‌شود.
- `ID` — شناسه: برای نشانه‌گذاری یک Element منفرد در صفحه و لینک‌دادن به آن استفاده می‌شود.

در متن رسمی، توضیح Link و Open in a new tab به‌اشتباه از عبارت `Div Block` استفاده کرده است. این خطا در سند حفظ می‌شود تا به‌صورت خاموش اصلاح یا به رفتار محصول دیگری نسبت داده نشود. این بخش بر پایه `CLM-KB-005-011` تا `CLM-KB-005-014` است.

### Style tab — تب Style

مقاله برای Style tab به هشت گروه تنظیمات اشاره می‌کند: `Layout`، `Spacing`، `Size`، `Position`، `Typography`، `Background`، `Border` و `Effects`. جزئیات کامل این گروه‌ها در مقالات مستقل آمده و بدون بررسی مستقل نباید به Heading نسبت داده شود. این بخش بر پایه `CLM-KB-005-015` است.

در مثال مرحله‌ای، `Layout` باز می‌شود و کنترل `Align Self` محل Heading را در Parent container تعیین می‌کند. گزینه‌های مستند آن `Start`، `Center`، `End` و `Stretch` هستند. انتخاب `Center` در مقاله صرفاً انتخاب مثال آموزشی است و Default محسوب نمی‌شود. این بخش بر پایه `CLM-KB-005-008` و `CLM-KB-005-009` است.

`Typography` برای تنظیم `Size` و `Font type` معرفی شده است. تصویر رسمی نمونه‌هایی مثل Font family، Font weight و Font size را نشان می‌دهد، اما چون متن مقاله فقط Size و Font type را توضیح می‌دهد، سایر جزئیات Typography باید تا بررسی مقاله مستقل Typography یا Fixture معتبر به‌عنوان Gap باقی بمانند.

## تفکیک documented / observed / derived / insufficient_evidence

### documented

- دامنه مقاله Editor V4 است و برای V3 به مقاله جداگانه ارجاع می‌دهد.
- افزودن و حذف Element از طریق `+`، Drag/Click و Delete key توضیح داده شده است.
- کاربرد Heading برای جلب توجه به بخش‌های مهم سایت و سفارشی‌سازی بدون کدنویسی ثبت شده است.
- General tab شامل Title، Tag، Link، Open in a new tab پس از Link، و ID است.
- Style tab به Layout، Spacing، Size، Position، Typography، Background، Border و Effects ارجاع می‌دهد.

### observed

- تصاویر رسمی، پنل `Edit Heading`، General tab، Style tab، Title، Tag با نمونه H2، Link، Open in a new tab، دسته‌های Style، Layout و Typography را نشان می‌دهند.
- موارد مشاهده‌شده فقط وقتی به Claim تبدیل شده‌اند که تصویر رسمی با وضعیت `inspected` در Image Evidence ثبت شده باشد.

### derived

- انتخاب Tag یک تصمیم معنایی/ساختاری برای محتواست، اما مقاله فقط اثر کلی آن بر فهم موتورهای جستجو و کمک احتمالی به SEO را مستند می‌کند.
- Heading از Style system مشترک V4 استفاده می‌کند، اما جزئیات هر گروه Style باید از مقاله مستقل همان گروه یا Fixture معتبر بیاید.

### insufficient_evidence

موارد زیر از این منبع به‌تنهایی قابل اثبات نیستند و نباید به‌عنوان رفتار محصول ثبت شوند:

- Default Tag یا Defaultهای دیگر.
- فهرست کامل گزینه‌های Tag.
- الزام یک‌بار بودن H1 یا قواعد کامل Heading hierarchy.
- Accessibility، Screen Reader و keyboard/focus behavior.
- Responsive controls و inherited responsive values.
- Dynamic Tags، Variables، Global Classes و Element States.
- URL/AJAX behavior، Runtime DOM/CSS، Markup خروجی یا Browser behavior.
- نسخه دقیق افزونه یا Free/Pro prerequisite.
