# Paragraph element — جزوه جامع فارسی Elementor Editor V4

> **دامنه این جزوه:** فقط متن و تصاویر تعبیه‌شده در صفحه رسمی Elementor با عنوان `Paragraph element` بررسی شده‌اند. صفحات فرعی لینک‌شده، از جمله مقاله‌های `Layout`، `Spacing`، `Size`، `Position`، `Typography`، `Background`، `Border` و `Effects`، بدون بررسی مستقل منبع factual این سند نیستند. مقاله V3 با عنوان `Text Editor widget` نیز فقط به‌عنوان ارجاع صفحه ثبت شده و محتوای آن به Paragraph element نسبت داده نشده است.

## 2. قرارداد وضعیت شواهد

- **documented:** ادعا به‌طور صریح در متن همین صفحه رسمی آمده است.
- **observed:** مورد مستقیماً در تصویر رسمی قابل مشاهده است، اما متن صفحه رفتار یا قرارداد آن را توضیح نداده است.
- **derived:** نتیجه‌ای محدود و قابل ردیابی از شواهد همین صفحه است؛ حقیقت مستقل محصول محسوب نمی‌شود.

نبود یک گزینه در این مقاله، اثبات نبود آن در محصول نیست.

## 3. خلاصه اجرایی

**[documented]** `Paragraph element` برای افزودن و سفارشی‌سازی متن وب‌سایت معرفی شده است.

**[documented]** صفحه دو مورد استفاده تکمیلی را نام می‌برد:

- `Blog posts` — نوشته‌های وبلاگ؛
- `Web page text` — متن صفحات وب.

**[documented]** مثال اصلی مقاله، افزودن چند جمله توضیحی در Hero section یک وب‌سایت نانوایی، زیر Heading، و سپس سفارشی‌سازی Typography برای هماهنگی با هویت سنتی برند است.

**[documented]** تنظیمات اختصاصی که خود مقاله توضیح می‌دهد محدود به این موارد است:

1. `Paragraph` — متن نمایش‌داده‌شده؛
2. `Link` — لینک‌کردن Paragraph؛
3. `Open in a new tab` — بازکردن لینک در تب جدید.

**[documented]** آموزش Style فقط یک مثال اجرایی از `Typography` ارائه می‌دهد: بازکردن Typography، انتخاب یک Font Family و انتخاب `900` از `Font Weight`.

**[documented]** صفحه هشت دسته Style مشترک را نام می‌برد، ولی کنترل‌های داخلی آن‌ها را در همین مقاله شرح نمی‌دهد:

- `Layout` — چیدمان؛
- `Spacing` — فاصله‌گذاری؛
- `Size` — اندازه؛
- `Position` — موقعیت؛
- `Typography` — تایپوگرافی؛
- `Background` — پس‌زمینه؛
- `Border` — حاشیه؛
- `Effects` — جلوه‌ها.

**[insufficient_evidence]** این صفحه برای Inline Editing، HTML Tag، Semantic markup، Color controls، Responsive controls، Dynamic Data، Classes، Variables، Element states، Accessibility خروجی، SEO و Runtime behavior توضیح صریح کافی ندارد.

## 4. اصطلاحات و ساختار رابط در خود منبع

### 4.1. Element و Widget

**[documented]** عنوان و معرفی صفحه از `Paragraph element` استفاده می‌کنند، اما در راهنمای مرحله‌ای عبارت `Paragraph widget` نیز به کار رفته است.

**[documented]** لینک معرفی بالای صفحه نیز با عبارت «See all the options available with the Paragraph widget» توصیف شده است.

**[derived]** این ناهماهنگی واژگانی برای نتیجه‌گیری درباره معماری داخلی، یکسان‌بودن Widget و Element یا سازگاری تنظیمات V3 و V4 کافی نیست.

### 4.2. General و Style، نه Content و Style

**[documented]** صفحه در راهنمای مرحله‌ای از `General tab` و `Style tab` نام می‌برد.

**[observed]** تصویر رسمی `Enter-the-paragraph-text-scaled.webp` دو Tab با عنوان‌های `General` و `Style` را در پنل `Edit Paragraph` نشان می‌دهد.

**[observed]** در همان تصویر، داخل General یک بخش با عنوان `Content` دیده می‌شود؛ بنابراین `Content` در تصویر نام Section است، نه نام Tab.

**[derived]** برای ثبت دقیق واژگان همین منبع، ساختار قابل اتکا چنین نوشته می‌شود: `General tab > Content section > Paragraph / Link` و در کنار آن `Style tab`.

## 5. افزودن و حذف Paragraph element

### 5.1. افزودن به Canvas

**[documented]** روش عمومی دسترسی و افزودن Element:

1. در Elementor Editor روی علامت `+` کلیک کنید؛
2. همه Elementهای موجود نمایش داده می‌شوند؛
3. Paragraph را کلیک کنید یا آن را به Canvas بکشید.

**[documented]** صفحه برای جزئیات بیشتر به مقاله فرعی `Add elements to a page` لینک می‌دهد، اما محتوای آن صفحه فرعی در این سند استفاده نشده است.

### 5.2. حذف از Canvas

**[documented]** روش حذف:

1. Paragraph element را با کلیک روی آن در Canvas انتخاب کنید؛
2. کلید `Delete` صفحه‌کلید را فشار دهید.

**[documented]** صفحه برای جزئیات بیشتر به مقاله فرعی `Delete elements from a page` لینک می‌دهد.

**[derived]** استفاده از کلید Delete فقط یک دستور ویرایشی در Editor است و به‌تنهایی شاهد Keyboard Accessibility خروجی Front-end نیست.

**[insufficient_evidence]** صفحه درباره حذف با منوی Context، Undo، تأیید حذف، بازیابی، میان‌برهای دیگر یا رفتار حذف در دستگاه لمسی اطلاعاتی نمی‌دهد.

## 6. هدف و موارد استفاده

### 6.1. تعریف رسمی

**[documented]** Paragraph element برای افزودن و سفارشی‌سازی متن وب‌سایت است.

### 6.2. مثال اصلی: Hero نانوایی

**[documented]** در مثال صفحه، شخصی با نام Bailey برای وب‌سایت یک نانوایی، چند جمله توصیفی را زیر Heading در Hero section قرار می‌دهد.

**[documented]** سپس Typography را با یک فونت قدیمی‌نما تغییر می‌دهد تا با هویت سنتی برند هماهنگ شود.

**[insufficient_evidence]** مقاله نام دقیق Font Family انتخاب‌شده در متن را اعلام نمی‌کند.

### 6.3. موارد استفاده تکمیلی

**[documented]** صفحه `Blog posts` و `Web page text` را به‌عنوان موارد استفاده دیگر فهرست می‌کند.

**[insufficient_evidence]** صفحه برای طول مناسب Paragraph، تعداد Paragraphها، ساختار مقاله، Read More، Columns، Lists، Quotes، Rich Text یا Markdown دستورالعملی ارائه نمی‌دهد.

## 7. راهنمای رسمی مرحله‌به‌مرحله

### مرحله 1 — افزودن Paragraph

**[documented]** Paragraph widget/element را به Canvas اضافه کنید؛ سپس گزینه‌های آن در Panel ظاهر می‌شوند.

**[insufficient_evidence]** متن صفحه محل دقیق Paragraph در فهرست Elementها، Category آن، Search keyword یا قابلیت Favorite کردن را بیان نمی‌کند.

### مرحله 2 — واردکردن متن

**[documented]** در `General tab` و زیر `Paragraph`، متن را وارد کنید.

**[observed]** تصویر `Enter-the-paragraph-text-scaled.webp` یک Text area با Label برابر `Paragraph` نشان می‌دهد که متن نمونه نانوایی داخل آن وارد شده است.

**[observed]** در Canvas همان تصویر، متن واردشده زیر Heading نمایش داده می‌شود.

**[insufficient_evidence]** تصویر و متن صفحه مشخص نمی‌کنند که تغییر متن با چه Triggerای ذخیره می‌شود، آیا Auto-save رخ می‌دهد یا آیا تغییرات به‌صورت Debounced روی Preview اعمال می‌شوند.

### مرحله 3 — بازکردن Link

**[documented]** برای افزودن لینک، روی علامت Plus کنار `Link` کلیک کنید.

**[observed]** تصویر `Click-the-plus-next-to-link-1-198x300.png` ردیف `Link` و دکمه Plus را در پایین Section `Content` نشان می‌دهد.

### مرحله 4 — واردکردن URL

**[documented]** URL صفحه مقصد را در `Link field` وارد کنید.

**[insufficient_evidence]** صفحه درباره اعتبارسنجی URL، Protocolهای مجاز، Relative URL، Dynamic URL، Anchor، Email، Telephone، File download یا خطای URL نامعتبر توضیحی نمی‌دهد.

### مرحله 5 — ورود به Style

**[documented]** روی `Style tab` کلیک کنید.

### مرحله 6 — بازکردن Typography

**[documented]** Section با عنوان `Typography` را باز کنید.

### مرحله 7 — انتخاب Font Family

**[documented]** یک Font را از Dropdown با عنوان `Font Family` انتخاب کنید.

**[insufficient_evidence]** صفحه فهرست Font familyها، Font source، Global font، Variable font، Fallback font، Loading behavior یا Font licensing را مشخص نمی‌کند.

### مرحله 8 — انتخاب Font Weight

**[documented]** برای برجسته‌ترشدن متن، از Dropdown با عنوان `Font Weight` مقدار `900` انتخاب می‌شود.

**[documented]** صفحه برای جزئیات بیشتر Typography به مقاله مستقل `Style tab – Typography` لینک می‌دهد.

**[derived]** مقدار `900` یک انتخاب در مثال آموزش است و نباید به‌عنوان مقدار پیش‌فرض Paragraph element ثبت شود.

**[insufficient_evidence]** مقاله مشخص نمی‌کند Font انتخابی واقعاً Weight 900 را دارد، Browser در نبود آن چه Fallbackی اعمال می‌کند یا خروجی CSS چگونه ساخته می‌شود.

## 8. تنظیمات General

### 8.1. Paragraph — پاراگراف

**[documented]** توضیح رسمی کنترل: متنی که در Paragraph نمایش داده می‌شود.

**[observed]** تصویر رسمی Label کنترل را `Paragraph` و نوع ظاهری آن را یک ناحیه ورود متن چندخطی نشان می‌دهد.

**[insufficient_evidence]** صفحه این موارد را توضیح نمی‌دهد:

- Placeholder یا مقدار پیش‌فرض؛
- محدودیت تعداد کاراکتر؛
- HTML مجاز یا پاک‌سازی HTML؛
- Line break و Paragraph break؛
- Paste از Word یا Google Docs؛
- Emoji، Unicode، RTL یا Bidirectional text؛
- Spellcheck، Autocomplete یا Browser extensions؛
- Sanitization و Escaping؛
- Shortcode؛
- Dynamic tags؛
- Rich-text toolbar؛
- متن شرطی یا Localization.

### 8.2. Link — لینک

**[documented]** با کلیک روی Plus می‌توان لینک وارد کرد.

**[documented]** بازدیدکننده با کلیک روی Paragraph، لینک را باز می‌کند.

**[derived]** عبارت «Visitors clicking the Paragraph» نشان می‌دهد دامنه کلیک در توصیف صفحه، خود Paragraph است؛ اما این عبارت جزئیات Markup یا Hit area دقیق را اثبات نمی‌کند.

**[insufficient_evidence]** صفحه روشن نمی‌کند Link روی کل Wrapper، متن داخلی، Anchor تو در تو یا ساختار دیگری Render می‌شود.

**[insufficient_evidence]** صفحه درباره لینک‌کردن فقط بخشی از متن، چند لینک در یک Paragraph، Nested links، Hover cursor، Focus ring، Visited state یا Disabled state اطلاعاتی ندارد.

### 8.3. Open in a new tab — بازکردن در تب جدید

**[documented]** اگر Paragraph لینک دارد، می‌توان Toggle با عنوان `Open in a new tab` را روشن کرد تا لینک در تب جدید باز شود.

**[insufficient_evidence]** صفحه مقدار پیش‌فرض Toggle را به‌صورت متنی اعلام نمی‌کند.

**[insufficient_evidence]** صفحه درباره `target`، `rel`، `noopener`، `noreferrer`، هشدار دسترس‌پذیری تب جدید یا رفتار مرورگر توضیحی نمی‌دهد.

## 9. Inline Editing — ویرایش درجا

**[insufficient_evidence]** صفحه رسمی Paragraph element عبارت `Inline editing` را در متن مقاله به‌عنوان قابلیت این Element توضیح نمی‌دهد.

**[observed]** تصویر قابل مشاهده، ورود متن در Panel سمت چپ را نشان می‌دهد؛ از این تصویر نمی‌توان پشتیبانی یا عدم پشتیبانی از ویرایش مستقیم متن روی Canvas را نتیجه گرفت.

**[insufficient_evidence]** شواهد این صفحه برای موارد زیر کافی نیست:

- Double-click برای ورود به Editing mode؛
- Cursor داخل متن روی Canvas؛
- Selection بخشی از متن؛
- Formatting toolbar شناور؛
- میان‌برهای Bold/Italic؛
- Paste روی Canvas؛
- تفاوت Panel editing و Inline editing؛
- رفتار Undo/Redo در Inline editing.

## 10. HTML Tag و Semantics

**[insufficient_evidence]** صفحه هیچ کنترل `HTML Tag` را برای Paragraph element نام نمی‌برد.

**[insufficient_evidence]** از نام Paragraph نمی‌توان بدون شاهد نتیجه گرفت که خروجی حتماً با عنصر HTML `<p>` ساخته می‌شود.

**[insufficient_evidence]** صفحه Generated markup، Wrapper، Class name، ARIA، Role، Schema، DOM order یا رفتار Nesting را نشان نمی‌دهد.

**[derived]** برای پایگاه دانش، نام محصول `Paragraph element` باید از ادعای Semantic HTML جدا نگه داشته شود؛ اولی مستند است و دومی در این صفحه اثبات نشده است.

---

## 11. لینک‌ها و Attributes

**[documented]** صفحه فقط `Link` و `Open in a new tab` را توضیح می‌دهد.

**[insufficient_evidence]** صفحه درباره `Custom attributes`، `ID`، `Class`، `aria-label`، `title`، `download`، `rel` یا Data attributes توضیحی ندارد.

**[insufficient_evidence]** وجود مقاله فرعی `Add and delete attributes` در Navigation سایت، به‌تنهایی اثبات نمی‌کند چه Attributeهایی برای Paragraph مجاز یا قابل استفاده‌اند.

## 12. Style tab

### 12.1. محدوده مستند همین صفحه

**[documented]** صفحه می‌گوید Elementها با Content و Style قابل سفارشی‌سازی‌اند و Tabهای `General` و `Style` را نمایش می‌دهد.

**[documented]** فهرست Style options به مقاله‌های مستقل زیر ارجاع می‌دهد:

| نام انگلیسی | ترجمه فارسی | پوشش جزئیات در همین صفحه |
|---|---|---|
| `Layout` | چیدمان | ندارد |
| `Spacing` | فاصله‌گذاری | ندارد |
| `Size` | اندازه | ندارد |
| `Position` | موقعیت | ندارد |
| `Typography` | تایپوگرافی | فقط مثال Font Family و Font Weight |
| `Background` | پس‌زمینه | ندارد |
| `Border` | حاشیه | ندارد |
| `Effects` | جلوه‌ها | ندارد |

**[derived]** نام‌بردن یک Category، شاهد وجود آن Category در دامنه مقاله است، ولی شاهد همه کنترل‌ها، مقادیر یا رفتارهای مقاله فرعی نیست.

### 12.2. Typography — تایپوگرافی
