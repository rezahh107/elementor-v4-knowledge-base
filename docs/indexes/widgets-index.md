# فهرست رسمی Widgets در Elementor Help Center

## دامنه سند

این سند فقط صفحهٔ Index رسمی `Widgets` را پوشش می‌دهد. محتوای مقاله‌های فرعی صرفاً به‌دلیل حضور لینک در Index به این سند نسبت داده نمی‌شود.

## وضعیت منبع

- نوع صفحه: Index موضوعی رسمی
- تعداد مقاله‌ای که صفحه هنگام پژوهش نمایش می‌دهد: `204 Articles`
- تاریخ آخرین به‌روزرسانی: صفحهٔ Index تاریخ مشخصی اعلام نمی‌کند؛ بنابراین `insufficient_evidence`.
- دامنه نسخه‌ای: صفحه ترکیبی است و مطالب V3، V4، Widgetها، Elementها و راهنماهای عمومی را کنار هم فهرست می‌کند.

صفحهٔ رسمی، مجموعه بزرگی از مقاله‌های خانواده Widgets را فهرست می‌کند. موارد قابل مشاهده در بخش نخست Index شامل نمونه‌های زیر است:

این Index علاوه بر Widgetهای کلاسیک، مقاله‌های مربوط به قابلیت‌های مشترک، Design System و برخی Elementهای Atomic را نیز در دسته Widgets نمایش می‌دهد.

## observed

- صفحه دارای عنوان `Widgets` و شمارنده `204 Articles` است.
- رابط فهرست از الگوی Load more استفاده می‌کند؛ بنابراین فهرست اولیهٔ قابل مشاهده لزوماً تمام 204 مقاله را یک‌جا نشان نمی‌دهد.
- در Navigation سایت، دستهٔ جداگانه‌ای با عنوان `Editor V4` نیز وجود دارد؛ پس حضور یک عنوان در Widgets به‌تنهایی برای طبقه‌بندی V4 کافی نیست.

## derived

- این صفحه برای Inventory و کشف URL مناسب است، اما منبع کافی برای مستندسازی کنترل‌ها یا رفتار هر Widget نیست.
- تعیین V3 یا V4 بودن هر مورد باید از صفحهٔ موضوعی خودش یا Index رسمی Editor V4 انجام شود.
- شمارندهٔ مقالات یک دادهٔ Rolling است و ممکن است تغییر کند.

## insufficient_evidence

این صفحه اطلاعات کافی برای موارد زیر ندارد:

- نسخه دقیق Elementor مرتبط با هر مقاله؛
- Free یا Pro بودن هر Widget؛
- کنترل‌ها و مقادیر پیش‌فرض؛
- رفتار Runtime، Responsive یا Accessibility؛
- فهرست Canonical و ثابت همه 204 مقاله بدون اجرای کامل Load more؛
- تاریخ انتشار یا آخرین ویرایش خود Index.

از این سند فقط برای موارد زیر استفاده شود:
