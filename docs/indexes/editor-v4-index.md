## derived

- این Index بهترین منبع رسمی برای تعیین Scope اولیهٔ Coverage پایگاه دانش V4 است.
- ترتیب نمایش مقاله‌ها احتمالاً ترتیب ثابت معماری یا اولویت محصول نیست؛ صفحه یک فهرست پویا است.
- برای ساخت Coverage کامل، باید Load more و تغییرات آیندهٔ Index به‌صورت دوره‌ای پایش شود.

## insufficient_evidence

Index موارد زیر را مشخص نمی‌کند:

- نسخه دقیق افزونه برای هر قابلیت؛
- وضعیت Beta، Stable یا Experimental هر مقاله؛
- Free/Pro و محدودیت پلن؛
- ترتیب وابستگی میان موضوع‌ها؛
- کنترل‌ها، defaults و رفتار Runtime؛
- تاریخ آخرین ویرایش خود صفحه Index.
